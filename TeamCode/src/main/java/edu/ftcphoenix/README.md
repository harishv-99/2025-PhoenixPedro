# Phoenix framework

Phoenix helps FTC teams build non-blocking TeleOp and Auto programs while one managed runtime owns
FTC lifecycle, loop order, and cleanup.

New to Phoenix? Start with [`Phoenix in one picture`](<fw/docs/getting-started/Framework Overview.md>),
[`set up and verify the project`](<fw/docs/getting-started/Build and Run.md>), and complete
[`your first Phoenix robot code`](<fw/docs/getting-started/First Phoenix Robot Code.md>). Next,
[`test its mechanism without hardware`](<fw/docs/getting-started/Test a Mechanism Without Hardware.md>).
Then [`choose a topic`](<fw/docs/getting-started/Beginner's Guide.md>) only when you need a deeper
answer.

The [`Phoenix documentation home`](<fw/docs/README.md>) is the canonical map for every guide,
example, troubleshooting path, and maintainer reference.
