# Phoenix framework documentation

The [`Phoenix docs home`](<docs/README.md>) is the one complete documentation map.

New to Phoenix? Read [`Phoenix in five minutes`](<docs/getting-started/Framework Overview.md>), then
follow [`Learn Phoenix`](<docs/getting-started/Beginner's Guide.md>). During build season, keep
the [`Phoenix Cheat Sheet`](<docs/reference/Phoenix Cheat Sheet.md>) nearby and start with
[`Common Problems`](<docs/troubleshooting/Common Problems.md>) when something is not working.

Phoenix uses one managed `FtcRobotOpMode`/`RobotProgram` lifecycle, source-driven Plants, one final
drive command path, and fresh single-use Tasks. The
[`Framework Principles`](<Framework Principles.md>) are the design authority for maintainers and
advanced extensions; they are not required before the learning path.
