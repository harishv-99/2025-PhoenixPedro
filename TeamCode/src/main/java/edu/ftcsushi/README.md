# Sushi framework

Sushi organizes the same repeated FTC work students know from `while (opModeIsActive())` or
`loop()`, while keeping hardware updates and STOP cleanup in one consistent path.

New to Sushi? Read [`How Sushi runs your code`](<fw/docs/getting-started/Framework Overview.md>),
[`set up and verify the project`](<fw/docs/getting-started/Build and Run.md>), and take the required
[`first software tour`](<fw/docs/getting-started/First Software Tour.md>). Then open the
[`Guide map`](<fw/docs/README.md>) and choose the robot outcome or deeper explanation you need.

The map links every focused [Build recipe](<fw/docs/build/README.md>), concept, example,
troubleshooting path, and maintainer reference.
