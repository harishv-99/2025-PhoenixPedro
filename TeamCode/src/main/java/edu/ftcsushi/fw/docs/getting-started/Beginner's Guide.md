# Learn one Sushi idea when you need it

Use this area to answer a question while reading or writing robot code. It is an on-demand concept
reference, not another required course. The [Build course](<../build/README.md>) introduces the
ideas through one outcome at a time; the [short tour](<First Software Tour.md>) previews changing
sensor observations, button actions, and timed work.

You can learn by reading without installing software, running a test, changing code, or owning the
example hardware. Each Build page supplies expected observations and their explanation. If you
choose to run supplied software or author a slice, use that page's optional paths.

| What do you want to understand? | Read this |
| --- | --- |
| What happens between pressing A and changing an intake request? | [Controls and intent](<learn-sushi/Controls and Intent.md>) |
| Which owner should hold hardware, button meanings, configuration, or status? | [Robot roles](<learn-sushi/Robot Roles.md>) |
| Which Plant shape matches the command and feedback my actuator supports? | [Plants and hardware](<learn-sushi/Plants and Hardware.md>) |
| How does unfinished work advance, finish, or cancel across loops? | [Tasks and autonomous](<learn-sushi/Tasks and Autonomous.md>) |
| What does a sensor fact, cached status, or software result establish? | [Evidence and experiments](<learn-sushi/Evidence and Experiments.md>) |
| A robot requirement changed; which part of the design should change? | [From requirement to robot](<learn-sushi/From Requirement to Robot.md>) |

For exact signatures, use the [categorized reference](<../reference/README.md>) or
[API type/member search](<https://harishv-99.github.io/2025-PhoenixPedro/api/>). For less common
patterns, select an [Advanced topic](<../advanced/README.md>) only when its stated prerequisites
match your question.
